# Pillars — স্তম্ভ

*Learning to learn · ৪টি বিষয়*

পুরো পদ্ধতিটা যে চারটা ভিত্তির উপর দাঁড়ানো।

- [ ] **Everything is a game** — প্রতিটা ক্ষেত্রেরই নিয়ম আছে, আর নিয়মগুলো জানা থাকলে খেলা অনেক সহজ হয়ে যায়। চাকরি পাওয়া একটা খেলা (সিভি, রেফারেল, interview-এর নিয়ম আছে), পদোন্নতিও একটা খেলা। যারা ভাবে "ভালো কাজ করলেই হবে", তারা নিয়মগুলো না জেনেই খেলে।
- [ ] **Feynman technique** — কোনো বিষয় সত্যিই বুঝেছেন কি না পরীক্ষা করার সবচেয়ে ভালো উপায়। চার ধাপ: বিষয়টা বেছে নিন → এমন সহজ ভাষায় লিখুন যেন একটা বাচ্চাও বোঝে → যেখানে আটকে যাবেন সেটাই আপনার ফাঁক, ওখানে ফিরে গিয়ে পড়ুন → আবার সহজ করে লিখুন। **আপনার জন্য এটা বিশেষভাবে কাজের**, কারণ লেখা আপনার শক্তির জায়গা।
- [ ] **Trunk based knowledge** — গাছের কাণ্ড আগে, পাতা পরে। মূল ধারণাগুলো (HTTP কীভাবে কাজ করে, reactivity কী, ডেটা কোথায় থাকে) হলো কাণ্ড; framework-এর syntax হলো পাতা। কাণ্ড শক্ত থাকলে নতুন framework শিখতে কয়েক দিন লাগে। শুধু পাতা শিখলে প্রতিবার শূন্য থেকে শুরু করতে হয়।
- [ ] **Efficiency trumps grit** — শুধু বেশি পরিশ্রম নয়, সঠিক পদ্ধতিতে পরিশ্রম। ভুল পদ্ধতিতে দশ ঘণ্টার চেয়ে সঠিক পদ্ধতিতে দুই ঘণ্টা বেশি ফল দেয়। সপ্তাহে ৪–৭ ঘণ্টা হাতে থাকলে এই কথাটা আরও বেশি জরুরি।
