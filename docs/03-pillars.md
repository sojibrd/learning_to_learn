# ব্লক ৩ — Pillars

*দিন ০১৮–০২১*

পুরো পদ্ধতির চারটা ভিত্তি — খেলার নিয়ম, সহজ ভাষায় লিখে ফাঁক খোঁজা, কাণ্ড আগে পাতা পরে, আর পরিশ্রমের চেয়ে পদ্ধতি। 🧠 (Trunk based knowledge)

> **ব্লক শেষে:** চারটা স্তম্ভের প্রতিটা একবার নিজের কাজে খাটানো হয়েছে?

### দিন ০১৮ · Everything is a game

- [ ] ১০′ এখনকার খেলার (চাকরি পাওয়া) তিনটা নিয়ম লিখুন যা "ভালো কাজ করলেই হবে" ভাবলে চোখে পড়ে না — যেমন রেফারেল, সিভির মূল শব্দ 🔁 🧠 (Everything is a game)

> **দিন শেষে:** তিনটা নিয়ম লেখা?

### দিন ০১৯ · Feynman technique

- [ ] ১০′ এই সপ্তাহে শেখা একটা ধারণা সাদা পাতায় এমন ভাষায় লিখুন যেন নতুন কেউ পড়ছে; যেখানে আটকালেন দাগ দিন, শুধু ঐ অংশ আবার দেখে আবার লিখুন 🔁 🧠 (Feynman technique)

> **দিন শেষে:** দাগ দেওয়া ফাঁক আর দ্বিতীয় লেখা আছে?

### দিন ০২০ · Trunk based knowledge

- [ ] ১০′ নিজের framework (Ember বা React) থেকে তিনটা "কাণ্ড" আর তিনটা "পাতা" দুই কলামে — কাণ্ড = অন্য framework-এও ফিরবে, পাতা = syntax 🔁 🧠 (Trunk based knowledge)

> **দিন শেষে:** দুই কলামে তিনটা করে?

### দিন ০২১ · Efficiency trumps grit

- [ ] ১০′ গত সপ্তাহের সবচেয়ে লম্বা বসাটা — কতটা সময় আসলে ফল দিয়েছে? পদ্ধতির একটা বদল লিখুন যাতে কম সময়ে একই ফল আসে 🔁 🧠 (Efficiency trumps grit)
- [ ] ১০′ [Examples](07-examples.md)-এর দৃশ্য ৩ — system design-এর কঠিন ধারণা: একটা ধারণা বাছুন, দৃশ্যের মতো সাদা পাতায় লিখুন, তারপর বন্ধ করে আবার — দ্বিতীয়টা ছোট হলো? 🧠 (Feynman technique · Test yourself)

> **দিন শেষে:** পদ্ধতির বদল লেখা, আর দৃশ্য ৩-এর মতো দুবার লেখা?
